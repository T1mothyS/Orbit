## 分级执行

| 层级 | 何时执行 | 命令与范围 |
| --- | --- | --- |
| Quick | 开发中或可明确界定的局部修改 | `npm run verify:quick -- --base <任务开始SHA>`；选择相关服务文件、静态检查和必要浏览器范围 |
| Full | 模块完成、重要 PR、认证/恢复/依赖/共享核心变化、未知影响面 | `npm run verify:full`；typecheck、UI lint、一次 build、全部服务测试、全部 Playwright、Gallery 生产排除、文档/hash 和 diff |
| Release | 正式发布前 | `npm run verify:release`；Full 加 92 项业务 Smoke 与原生弹窗检查（数量仅为本次历史基线，实际以结果为准）；相关平台和外部验收另外完成 |
| 文档 | 非帮助输入的普通说明/归档 | `npm run docs:check` 与 diff；七份帮助输入变化还需生成索引和产品帮助回归，Quick 自动选择 |

Quick 默认包括当前未提交的暂存/未暂存/未跟踪文件；任务已提交后用任务开始 SHA，避免把空差异当通过。`--list` 只显示计划；`--files <路径...>` 仅用于明确的开发范围，不替代整项任务完成检查。基线不可解析会失败，不能报告 Quick 成功。未映射输入或共享高风险变化升级 Full；CI 无论参数如何都不能降为 Quick。

同一任务中，相关源码、锁文件、配置、截图基线、平台/Node/浏览器和字体环境未变时，可引用有效结果；失败修复后重跑受影响项。没有跨任务缓存、自动跳过 Full/Release 或永久成功凭证。正式 CI 每轮重新执行完整闸门。runner 在系统临时目录输出各步骤耗时、日志和 result.json，失败原样返回非零。

build 已包含 Tools、项目成长和帮助生成，不再额外调用同一轮检查。Electron 构建使用进程级合法 HTTPS ELECTRON_APP_URL（runner 默认构建占位地址），不改仓库 .env。跨项目只在相关合同变化时显式提供 DAILY_REPORT_V2_ROOT 并运行 `npm run test:cross-project`，不访问另一项目的个人配置。

## 浏览器范围与隔离

| 入口 | 运行条件和保护目标 |
| --- | --- |
| Gallery | Quick 的 src/ui、design、dev 改动；只启动无业务 API 的 /dev/ui，验证基础控件、焦点、减动、对比度和布局 |
| 账户/Settings/第二阶段业务 | Quick 的设置、帮助和相关导航；先构建当前 Web，再启动独立合成 API；真实页面验证保存、冲突、草稿、身份和帮助行为 |
| 完整 Playwright | Full/Release、CI；两套服务各启动一次，四尺寸明暗和批准截图比较保持 |
| 业务 Smoke | Release，或记事/图片/筛选/阅读/导出/壳变动时提前运行 mobile-compact-browser-smoke.cjs；保留独特业务链及故障断言 |
| 原生弹窗 | Release，或 confirm/beforeunload/未保存保护/自动化引导变化时提前运行 native-dialog-browser-smoke.cjs |
| 其余专项 Smoke | 按领域和变更运行，历史专项没有证明对等替代前保留；不作为每次小改动的统一前置 |

浏览器和依赖：首次可用 `npx playwright install chromium`；已有 Edge 时可在进程级设置 ORBIT_BROWSER_CHANNEL=msedge。输出默认系统临时目录，ORBIT_UI_QA_DIR 可指定目录。服务仅 loopback、临时 DATA_DIR，后台邮件/Push/主动任务和真实模型关闭，不加载生产配置。Release 的两个可变 Smoke 分别创建新的服务/数据库；不为了复用登录共享可变账号状态。

第三轮导航后的业务 Smoke 通过邮箱独立页返回今日再进入原对话，验证未发送草稿仍在；知识库浮层选择立即生效，排序失败保留已保存值及筛选，Escape 关闭并归还焦点。原生弹窗 Smoke 的设置/资料返回目标为今日，仍保留真实 confirm/beforeunload、取消留稿、确认离开和浏览器返回断言。平台截图必须覆盖展开改密及全部设置/帮助页面，不能把只检查首张账户截图的专项结果当作完整视觉差异清单。

设置视觉账号按尺寸/主题隔离并固定合成提醒邮箱和保存时间，避免与并行保存用例共享状态；普通业务用例继续使用真实隔离 API。周期提醒深链接回归在编辑保存后等待列表 GET 完成与网络空闲，再断言 URL 已消费且弹窗保持关闭，防止只观察保存瞬间而漏掉刷新重开。

Full/Release 的 UI 覆盖 390×844、430×932、768×1024、1440×900 明暗主题，包含长文本、键盘、错误/加载/禁用、焦点返回与无横向溢出；低高度 Sheet、对比度与 reduced-motion 由 Gallery 保护。业务矩阵不能由 Gallery 代替。

周期提醒紧凑 Demo 的 `round3 reminder demo` 回归覆盖四尺寸明暗下三种类型与生活事务四种周期的默认主区无内部滚动、可见字段和提交区；展开更多设置及420px低高度检查正文滚动、关闭/提交可达和未保存取消。另通过隔离真实 API 验证三类型创建/编辑后折叠配置、原分钟值不变，以及原生校验、保存失败保留、保存中关闭/重复保护。Select 浮层须位于所属原生 Dialog 内并可实际选择。截图为候选，不能在用户确认 Demo 前批准基线或推进后续阶段。

批准状态以 tests/ui/visual-policy.json 为准，平台基线与 Linux 来源分别位于 tests/ui/baselines/ 和 linux-provenance.json。普通比较缺图或差异必须失败；CI 不更新或批准基线。候选采集保留失败状态，只供审阅，不作为通过。保留 threshold/maxDiffPixelRatio，不增加盲目重试；可变账户/设置测试仍禁止重试。`node scripts/verify-ui-build.mjs` 验证开发 Gallery 未进入公开产物。

### 合成浏览器与原生弹窗

单独调试时先构建，再启动 `node --import tsx scripts/orbit-ui-preview.ts 4198 --iteration --browser-audit`，创建新的合成数据库并提供普通端 4198、自动化端 4199。端口被占用时换一对空闲端口，不停止其他任务的进程。

给 Smoke 进程设置 ORBIT_UI_AUDIT_SYNTHETIC=true、ORBIT_PREVIEW_URL=http://127.0.0.1:4198、ORBIT_AUDIT_URL=http://127.0.0.1:4199，然后执行对应脚本。普通模式验证实际 confirm/beforeunload；ui-audit 模式只处理显式合成样本，不能作为生产绕过保护的方法。

scripts/browser-automation.cjs 必须在导航前附加；每次原生确认先用 expectDialog 指定类型、消息和 accept/dismiss。未知弹窗默认拒绝并记失败；权限按合成 origin 显式授予，不改全局浏览器。IAB 引导仅在 serve + ui-audit + 显式合成 + loopback 条件生效。具体故障现场保留在日期快照，不由工具限制推定产品失败。

## 覆盖映射与测试增长

| 风险 | 服务层 | 浏览器/Smoke | 是否可以直接删减 |
| --- | --- | --- | --- |
| 账号身份、改密和恢复 | account-security、http-security、persistence | account 的真实改密、跨页签/旧响应/敏感输入 | 不可；分别保护服务安全与页面集成 |
| Cloud 共享草稿、409、账号切换 | settings-state、context、notification-preferences | settings 的真实保存/跨分类/换账号 | 不可；模型状态与 HTTP/路由集成不同 |
| 基础控件与业务页面 | ui-lint、ui-request-error | Gallery 与 account/settings | 同视口/主题不等于同风险，保留 |
| 未保存与原生弹窗 | browser-automation、composer-draft 等 | native-dialog 的实际 dialog 与自动化引导 | 不可被普通 Dialog 或状态单元测试替代 |
| 业务布局/阅读/图片 | 各领域服务 | mobile Smoke 的六业务页、搜索、图片/失败/下载 | 与设置矩阵的页面不同；调整为按领域/Release |
| 帮助生成与用户答案 | maintenance-scripts、system-assistant | /help、生成索引后的真实查询 | 同时验证原文标记、片段权限、常见问题与接口门禁 |
| 维护工具 | maintenance-scripts | 不需要新增视觉套件 | 合成数据验证选测升级、归档原文/幂等/恢复/并发保护 |

未发现可以直接证明对等替代并安全删除的现有套件，本轮删除测试数为零。重复覆盖比例不能由题目相似或静态断言数量推断；未逐条证明时不报告百分比。新增测试优先扩展已有套件，说明保护的具体失败模式，避免为相同风险再建平行 Smoke。

测试用例、运行时断言、静态断言调用点、Smoke 检查项、检查组及截图比较数量分别统计；它们都不能替代实际耗时。Playwright 并行用例耗时之和不是整套 wall time；落盘 PNG 数也不等于截图比较次数。

## 发布与外部层级

CI 始终运行完整服务、类型、UI 边界、构建、批准截图和产物隔离；不因 Quick 或本地复用降级。Linux artifact 必须属于冻结目标；Windows 通过不能替代 Linux 比较。当前 CI 与部署流程见 [RELEASE](RELEASE.md)，本次日期证据见归档。

Release runner 仅执行隔离 Web 回归，不自动 push、tag、发布、部署、发送邮件、调用真实 AI 或触发手机。Electron/Android 原生构建运行、跨项目、生产恢复、OAuth 自然刷新、长期 CalDAV、真实 SMTP/IMAP 和手机自然通知按本次影响与授权分别验收。PUBLISHED/QUEUED、health、PM2、SMTP accepted 与收件箱/系统展示不是同一结果。

## 文档与流水维护

`npm run docs:check` 检查当前 Git 文档及待提交新文档的相对链接/锚点、索引目标、版本来源、帮助输入和 hash；`--generated` 额外要求生成索引与当前输入完全一致。历史项目成长引用按 commit:path 验证，评测 JSON 稳定路径不移动。外链可用性和语义准确性仍需针对性审阅，不把静态检查当作全自动文档审计。

流水与历史版本的滚动条件、原文保护、备份和恢复只维护在 [归档 runbook](archive/README.md#滚动维护流程)。


第二阶段的 `tests/ui/stage2.spec.ts` 随 app/all 范围执行，覆盖帮助滚动、视口导航菜单、搜索内容行与紧凑 Context 输入；C2追加四尺寸明暗的目录/阅读返回、日报、成长/架构、活动报告/筛选、经历与研究，以及研究证据失败/确认取消、低高度筛选。显著布局重组的截图以候选保存在测试输出；`ORBIT_UI_VISUAL_CANDIDATES=1` 运行只能证明功能与候选采集，必须另行报告批准基线的比较状态，不可将其称为全部视觉比较通过。原有批准图和断言保留，最终由审阅后的显式基线流程接纳。


C3追加今日/待办四尺寸明暗、菜单键盘与嵌套编辑、真实隔离API完成失败/重试/重开/删除取消、低高度脏表单与邮箱确认失败保留；AI/记事/邮箱场景同时保留真实截图。旧待办专项 `scripts/unscheduled-browser-smoke.cjs` 使用合成HTTP，在新菜单/选择器/手机浮层几何下继续保留全部历史/编辑/状态与焦点断言。复制预览另存业务Smoke截图供主动视觉复查。


C4追加登录/注册、日历四视图/菜单/编辑、后台分区/账户与Tools中心四尺寸明暗；管理员失败回滚、危险确认取消、低高度操作与关闭、日志手动筛选及读取/清空失败保留；真实隔离登录重试与受保护目标恢复。五个工具按390/1440检查键盘、局部滚动、保存恢复、扑克JSON备份往返、动画/滑杆和用量筛选；支付宝图表使用应用既有Plotly CDN，需联网，不能将网络不可用当作图表通过。复用Bearer的夹具通过真实auth/me建立每个测试上下文的网页Cookie，不放宽认证或限流。


C5补充430×520、705×402时间浮层可见/键盘/返回焦点用例；真实200%缩放另用独立临时Edge配置调用tabs.setZoom(2)，以DPR和CSS视口核实缩放，CDP采集完整可见表面。该机器专项不替代正式Windows/Linux批准图或实体软键盘验收。

## 第三轮反馈回归

`tests/ui/round3.spec.ts` 覆盖四尺寸明暗的静态帮助收纳、统一通知组、即时筛选与失败恢复、头像经历入口、页头移除及提醒必填标记；计划结果按操作类型区分，通知/主动提醒的图标动作和 Tooltip 另有场景。`stage2.spec.ts` 的知识库回归随确认后的即时筛选合同调整，仍保留排序、阅读返回、低高度浮层及焦点断言。候选截图与严格比较分别报告，不自动批准新图。

`tests/ui/round4.spec.ts` 覆盖二级路由/侧栏/tab 同步、设置共用头像、固定返回今日、统计默认值保存失败及历史快照、分钟范围应用/取消/刷新、三秒俏皮话终态停止，以及架构离屏暂停、无 URL 自动推进和减少动态效果深链接。四尺寸明暗保存候选图和关键动画帧；原有设置、账户、业务详情、提醒弹窗断言随明确的新导航合同调整，批准图与阈值不变。

本轮另覆盖430×520自定义范围及嵌套时间浮层、无效范围禁用、八个独立入口固定返回；受控时钟配合模拟visibilitychange验证后台停止，等待网络刷新后核对真实请求终态。原帮助滚动断言改为页尾可达，保留底部内容验证，不再查找已移除的“返回对话”。

架构手动暂停/继续还验证当前阶段重新获得完整绘制与停留时间；离屏/后台仍保留剩余时间，避免手动继续后节点尚未绘完就跳到下一阶段。
