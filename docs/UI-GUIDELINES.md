# Orbit UI Guidelines

本文档是前端和 Codex 修改界面时的共同约束。目标是保持快速扫读、明确状态和小屏可用，不用无关的装饰或复杂依赖替代信息层级。

## 1. 布局与断点

- 页面先保证 min-width: 0、可收缩和内容内部滚动，不能用固定宽度撑开父级。
- 主应用当前使用 1199、899、850、760、680、640、560、520 等已有断点；新增断点前先确认现有规则是否已覆盖。
- 1440px 及以上优先利用稳定的内容最大宽度；日程工作区可以全宽，Newsletter 日报阅读页保持约 680px 的文档阅读宽度。
- 899px 以下产品壳导航改为两行；640px 以下 Settings V2 变为接近全屏的纵向布局；不要恢复桌面浮窗模式。
- 页面、Dialog、抽屉、卡片和表单都要检查 390×844、430×932、768×1024、1440×900。

## 2. 信息层级和容器

- Card 只承载独立的信息块；日报正文优先使用文档阅读模式，不要叠加无意义的卡片。
- 页面标题、辅助说明、主要动作和状态应有明显层级，错误/加载/空状态不能只依赖颜色。
- 外层容器、Dialog body 和可滚动区域必须设置 min-width: 0、min-height: 0；滚动内容不应把关闭栏或主要操作推出视口。
- 长标题、邮箱、用户 ID、模型名、令牌和错误信息使用 overflow-wrap 或内部滚动，不得撑宽页面。

## 3. 控件规则

- Button、Input、Select、Switch 等控件优先通过共享 class 和现有组件控制尺寸，不要重复写 inline style。
- 按钮组使用 flex-wrap；按钮文字允许换行，危险操作必须有明确确认和可取消路径。
- 可交互区域在触屏上至少接近 44px；图标按钮必须有可见的 hover/focus 状态和 aria-label。
- Switch 同时表达视觉状态和 aria-checked/disabled 状态；loading 时阻止重复提交并保留错误反馈。
- 表单标签和辅助说明与控件保持关联；键盘焦点、Escape、返回焦点和 Dialog 关闭行为要可预测。

## 4. Settings Row 规范

Settings V2 使用 SettingSection、SettingRow 和统一 settings.css：

- 桌面为 minmax(140px, 170px) 的说明列加可收缩控件列。
- 800px 以下缩窄说明列；640px 以下变为标签、说明、控件纵向排列。
- 输入、选择器、状态面板和按钮组不超过父级宽度。
- 所有设置领域保持挂载以保留未保存草稿，但关闭/取消必须清理敏感输入。

## 5. 主题、图标和媒体

- 明暗主题使用现有变量和组件主题，不用固定白色/黑色覆盖主题。
- 独立阅读路由也要恢复用户保存的主题，直接打开链接或刷新不能丢失主题。
- 导航图标只在确有信息价值时使用；统一尺寸、透明边界和 active/hover 反馈。
- 图片使用 max-width: 100%；表格和 code block 在自己的容器内滚动。
- 静态资源优先使用项目已有依赖或 SVG/WebP；为节省很小体积不要引入大型图片处理依赖。

## 6. 验收清单

每次涉及 UI 的修改至少检查：

1. 页面能打开，核心控件存在，没有严重 console error。
2. 浅色和暗色主题都可读。
3. 390×844、430×932、768×1024、1440×900 无页面横向滚动。
4. 长文本、错误、loading、disabled、empty 和弹层状态不破坏布局。
5. 键盘焦点、触屏操作、返回和取消路径可用。
6. 资源 MIME、大小和构建输出符合当前部署约束。

纯视觉变化不能以 typecheck 或 build 代替实际渲染检查。

## 7. 挂起待办和手机阅读

- 挂起待办的“查看全部”使用标题右侧展开图标，触屏点击区域至少 44px；不另设卡片上方的大按钮。卡片只展示未完成项，管理弹窗默认包含已完成项。
- 管理弹窗相对浏览器视口居中，通过 Portal 放在 body，避免祖先 transform 改变定位；四周留白，长列表内部滚动。遮罩、关闭按钮及 Escape 可关闭，关闭后焦点回入口；编辑退出有未保存确认，保存中禁止关闭和重复提交。
- 手机知识库阅读的导航规则以 [知识库功能说明](LIBRARY.md) 为准；主菜单隐藏规则必须随主壳样式加载，不能依赖尚未加载的文章组件。懒加载/失败占位也必须有返回路径。

## Orbit 对话工作区

宽屏显示会话侧栏、对话和既有记事板；窄屏以抽屉打开会话/记事板。生成状态只影响对应请求，不能禁用整个页面；下一条输入加入队列，取消与失败重试有明确反馈。知识卡片显示约两行摘要，未引用候选折叠；日程结果卡片允许键盘打开并复用现有编辑器。

### 对话与设置基础系统

普通回复使用安全 Markdown 子集（标题、列表、加粗、代码、链接），不执行 HTML、图片或任意协议链接。正文桌面 14px、手机 15px，行高 1.65；确认草稿与执行成功分别表达，终态只由服务器结果决定。已处理提醒移除动作按钮，历史动作未知时显示“已处理”。读取旧内容时不抢滚动，提供“有新回复”。

请求状态由认证事件流提供实际步骤，断线沿用轮询；不显示推理过程、虚构百分比或重复 Thinking。长任务显示耗时和取消，工具来源与步骤可展开。设置搜索只索引已挂载、当前角色可见的名称/描述/别名，绝不索引输入值。搜索结果滚动定位、聚焦可用控件并短暂高亮；稳定公开入口应给 SettingRow 显式 id。

Motion 沿用 CSS 与 TDesign 生命周期：按压/悬停 80ms（反馈）、消息和状态 120ms（新增/变化）、浮层 160ms（层级）、侧栏 220ms（空间）。使用统一 easing 和 opacity/小幅 transform；不做整页飞入、布局动画或弹跳。连续操作可直接反转，最长 240ms。reduced-motion 禁止位移、循环与平滑滚动，保留静态状态。实现位于 src/styles/orbit-foundation.css。

模型能力/Provider 选择沿用语义输入颜色、边框和紧凑尺寸，未知模型显示读取提示，不能只留下空下拉箭头。暗色日历标题使用主文字色，周期页面使用实色背景；聊天和设置原生链接使用主题色，暗色提高亮度，避免浏览器默认深蓝。宽屏导航显示短名称，窄屏保留可访问标签。窗口变化的过渡帧和最终稳定布局分开验证。
