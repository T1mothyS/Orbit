# Orbit UI Guidelines

本文档是前端和 Codex 修改界面时的共同约束。目标是保持快速扫读、明确状态和小屏可用，不用无关的装饰或复杂依赖替代信息层级。

## Orbit UI 统一迁移与 Agent Change Playbook

Status: 第三轮 B—F 已实施，候选图待审阅；第一轮本地收口；2026-10-18 用户确认 A/B/C 及页头调整后继续验收。`src/design/` 是 token 值来源，`src/ui/` 是新基础控件唯一入口；`/dev/ui` 是不读取账号数据的开发 Gallery，正式构建不包含。下方历史 TDesign/class 规则仅适用于未迁移区域。迁移去向及退出条件见 [前端台账](FRONTEND-DEBT.md)，平台截图和发布闸门见 [测试矩阵](archive/engineering/TEST-MATRIX-20261018.md#2026-10-18-批准基线与第一轮收口)。

1. **先定位：** 阅读 [PROJECT-MAP](../PROJECT-MAP.md)、本文、目标领域合同和测试。普通改动应只需 ui 与目标 feature，不以通读 App/全部 CSS 为前提。
2. **控件入口：** 从 `src/ui` 引用，不直接依赖 Base UI/TDesign 或它们的类型，不复制控件和浮层生命周期。
3. **权威来源：** 颜色、字体、间距、圆角、运动和层级值在 design；布局/响应式/浮层规则由本文维护。旧变量只做映射。
4. **新增组件：** 现有 API 无法表达明确、可复用需求时再新增；同步语义、完整状态、键盘/触屏、Gallery 和测试，不建平行 UI。
5. **禁止：** 页面重定义控件外观、硬编码主题、全局 override 修局部布局、UI 导入认证/API/业务状态、扩大 allowlist 通过检查。
6. **职责：** ui 管控件；feature 管领域状态与操作；page 组合页面；layout 管共享空间/容器。共享规则沿用 services/utils，基础 UI 不调用业务。
7. **最低检查：** ui:lint、typecheck、test、build、test:ui、git diff --check；核对 Git/版本/文档。工程通过不代表视觉通过。
8. **按风险追加：** 视觉检查明暗/长文本/截图；交互检查触屏/键盘/焦点/返回；状态检查失败/并发/草稿；路由检查旧链接/深链接/历史；安全检查认证/隔离/失效/持久化。
9. **冲突顺序：** 当前代码事实与有效合同 → 用户确认目标 → 本文及组件合同 → 迁移/回归 → 删除旧实现。未知业务先核实；行为改变或不可逆决策才询问。

当前账户实现从 `features/settings/account/AccountPage` 进入；`layouts/SettingsFrame` 只组合空间与导航，feature 提供分类及业务。认证的唯一所有者是 main 中的 `AuthProvider`；普通功能使用 `useAuth`，不再为每个控件各自请求身份。Settings 的父组件不按 pathname 重挂；共享草稿只从 SettingsState 访问。新增图片选择、头像和文本导航复用 ui 的 FilePicker/Avatar/TextLink。敏感表单只留组件内存，离开即卸载；不得加入 Settings 草稿缓存。接口与失效边界见 [账号安全合同](ARCHITECTURE.md#账号密码与登录失效)。

新体系使用语义色、有限按钮变体、中文系统字体与轻量状态运动；输入至少 16px，触屏至少 44px。页面可以布局，不能重写 `.oui-*` 外观。Dialog/Sheet 统一名称、滚动、焦点和 busy 关闭保护，业务只提供内容/操作/状态。

**视觉判断不限于 lint。** 主动检查层级、节奏、对齐、留白、密度、控件比例、主次动作、手机组织和动效；技术合规但笨重粗糙时继续修正。A 确认 Gallery 整体视觉，B 确认账户真实页四组设备/主题，C 确认 Settings 分类一致性。常规批次不逐个审批。已迁移区域同步删除旧实现；兼容映射最后使用方退出即删。

## 1. 布局与断点

- 页面先保证 min-width: 0、可收缩和内容内部滚动，不能用固定宽度撑开父级。
- 主应用当前使用 1199、899、850、760、680、640、560、520 等已有断点；新增断点前先确认现有规则是否已覆盖。
- 1440px 及以上优先利用稳定的内容最大宽度；日程工作区可以全宽，Newsletter 日报阅读页保持约 680px 的文档阅读宽度。
- 899px 以下产品壳导航改为两行；Settings 在 768px 以下使用分类首页 → 独立子页，隐藏业务导航；768px 以上左分类、右当前页面，不恢复旧弹窗模式。
- 页面、Dialog、抽屉、卡片和表单都要检查 390×844、430×932、768×1024、1440×900。

## 2. 信息层级和容器

- Card 只承载独立的信息块；日报正文优先使用文档阅读模式，不要叠加无意义的卡片。
- 页面标题、辅助说明、主要动作和状态应有明显层级，错误/加载/空状态不能只依赖颜色。
- 外层容器、Dialog body 和可滚动区域必须设置 min-width: 0、min-height: 0；滚动内容不应把关闭栏或主要操作推出视口。
- 长标题、邮箱、用户 ID、模型名、令牌和错误信息使用 overflow-wrap 或内部滚动，不得撑宽页面。

## 3. 控件规则

Mobile Compact 沿现有组件实施：手机页面/卡片通常12px内边距，间隔4/8/12px；输入16px、正文保留阅读行距。六入口仍为六等分，44px触控区内放24px图标和更小的选中背景；手机产品壳两行各44px。聊天无图片/提示/多行时输入区约108px（另计安全区），长输入自动增高至上限，不能全局缩字体。

知识库/日报手机筛选复用 `CompactFilterSheet` 原生dialog：临时编辑、应用、取消、重置、条件数量、内部滚动、固定可达操作与焦点返回。高频操作直达，低频导出到设置、邮箱导入/Research到头像菜单；全局搜索统一紧凑圆角输入。头像菜单分组并限制高度，版本弱化到底部。两组 `OrbitSegmentedControl` 共用pill滑块、整段点击、横向手势和方向键，降低运动偏好时取消位移。

- Button、Input、Select、Switch 等控件优先通过共享 class 和现有组件控制尺寸，不要重复写 inline style。
- 按钮组使用 flex-wrap；按钮文字允许换行，危险操作必须有明确确认和可取消路径。
- 可交互区域在触屏上至少接近 44px；图标按钮必须有可见的 hover/focus 状态和 aria-label。
- Switch 同时表达视觉状态和 aria-checked/disabled 状态；loading 时阻止重复提交并保留错误反馈。
- 表单标签和辅助说明与控件保持关联；键盘焦点、Escape、返回焦点和 Dialog 关闭行为要可预测。
- 未保存资料仅在 dirty 时注册 beforeunload，保存、取消和卸载后移除；正常导航/刷新保留取消保护。自动化原生 dialog 的应答及合成预览旁路见 [测试矩阵](archive/engineering/TEST-MATRIX-20261018.md#2026-10-09-原生确认框与浏览器自动化)，不得通过删掉用户保护修测试。
- 日程时间弹层复制当前值到内部 draft，仅“确定”写回父表单；取消、Escape 和 Tab 离开丢弃 draft。小时/分钟复用原生列表选择，方向键移动，Enter/Space 依次进入分钟及确认按钮；关闭回到时间入口，Tab 离开继续到下一个控件。开始时间确认时才联动结束时间，跨日结束日期须保留并展示。
- 从个人菜单打开设置时保留来源；显式返回恢复 `[data-account-menu-trigger]` 的焦点，不聚焦已关闭菜单项。设置内分类/页签导航和 AI/全局搜索定位共用路由映射，旧模块入口返回业务主页，避免重定向循环。
- 记事操作名称使用“动作 + 当前卡片编号”，正文只作为内容呈现，不重复放入选择、编辑、复制、合并或恢复按钮名称。
- 个人菜单邮箱是展示文字，点击后菜单保持展开。菜单、搜索和设置危险确认复用 src/ui 的浮层生命周期与键盘焦点，不恢复原生 details 的手写失焦折叠，也不另建焦点陷阱。

## 4. Settings Row 规范

Settings 分类高亮由 canonical 路由决定，页面使用一个主滚动区；当前页标题、旧 ID 及搜索目标按同一映射定位，导航不能抢夺正文滚动。手机知识库阅读控制条铺满滚动区域顶端、用不透明背景覆盖正文；箭头返回保留44px触控区及无障碍名称。

Settings V3 使用 `src/ui` 的 Section/SettingRow；feature 的 SettingFields 只补语义 ID。桌面说明与操作分列，手机按说明、控件、反馈重组；控件尺寸和主题由 ui 维护。父路由持有 Cloud Context 与通知偏好，已访问分区保留普通编辑状态；隐藏分区停止请求，凭据和一次性令牌离开分区清空。页面 CSS 只负责布局，不覆盖基础控件。

设置搜索只在 Settings 顶栏保留一个入口，不在分类正文重复放置。桌面输入框相对整个窗口居中，宽约320–480px，不填满侧栏后的剩余空间；手机使用放大镜，点击后在同一顶栏向左展开并聚焦，暂时收起Orbit字样，保留Logo和头像；输入框不占第二行，只有搜索结果向下弹出。关闭按钮或Escape收起并返回入口焦点，选择结果仍走原设置ID定位和未保存保护。独立页面的返回入口统一为内容左上角 ArrowLeft IconLink，目标 `/today`，保留44px触控区、完整提示和未保存保护。Settings 右上角复用 AppShell 的 AccountMenu；分类子页返回设置列表仍是内部导航。

头像菜单不重复提供个人资料和账户/头像入口，两者统一从设置的账户与安全访问，旧深链仍保留。项目成长与个人活动报告取消页面整体最大宽度，滚轮在两侧边距也生效，不改其他工作区的滚动所有权。

手机设置首页按图标、标题、下方说明与右箭头排列，项目之间有分隔线；首页不展开二级入口、不把分类说明藏入问号。进入分类后使用原有页签，桌面侧栏及具体设置表单的说明/帮助保持原方式。AI对话顶部清空与记事板使用quiet图标按钮，未完成记事数浮在纸张图标右上角；常态无文字，hover/focus使用Tooltip，禁用态保持无框的图标语义。手机日报筛选同样只显示图标并保留条件数。

使用指南保留七个主题及稳定锚点，每节标题右侧放站内跳转箭头与“询问AI”按钮，下方直接显示说明和简短操作步骤；不重复放顶部目录和通用询问提示。询问按钮可见名称简短，无障碍名称带主题，仍只向原会话草稿追加受控问题，保留文字和图片，不自动发送。

## 5. 主题、图标和媒体

- 明暗主题使用现有变量和组件主题，不用固定白色/黑色覆盖主题。
- 普通小文本链接复用 `--orbit-link-color` 和 `--orbit-link-hover-color`，常态/visited 保持下划线，hover/active 使用主题正文色，可见焦点保留轮廓。对比度至少 4.5:1；同时检查页面和 TDesign Portal 的实际 token，不能仅按根节点颜色推断。
- 独立阅读路由也要恢复用户保存的主题，直接打开链接或刷新不能丢失主题。
- 导航图标只在确有信息价值时使用；统一尺寸、透明边界和 active/hover 反馈。
- 图片使用 max-width: 100%；表格和 code block 在自己的容器内滚动。
- 静态资源优先使用项目已有依赖或 SVG/WebP；为节省很小体积不要引入大型图片处理依赖。

## 6. 验收清单

每次涉及 UI 的修改至少检查：

1. 页面能打开，核心控件存在，没有严重 console error。
2. 浅色和暗色主题都可读。
3. 390×844、430×932、768×1024、1440×900 无页面横向滚动。
4. 长文本、错误、loading、disabled、empty 和弹层状态不破坏布局。
5. 键盘焦点、触屏操作、返回和取消路径可用。
6. 资源 MIME、大小和构建输出符合当前部署约束。

纯视觉变化不能以 typecheck 或 build 代替实际渲染检查。

## 7. 挂起待办和手机阅读

- 挂起待办的“查看全部”使用标题右侧展开图标，触屏点击区域至少 44px；不另设卡片上方的大按钮。卡片只展示未完成项，管理弹窗默认包含已完成项。
- 管理弹窗相对浏览器视口居中，通过 Portal 放在 body，避免祖先 transform 改变定位；四周留白，长列表内部滚动。遮罩、关闭按钮及 Escape 可关闭，关闭后焦点回入口；编辑退出有未保存确认，保存中禁止关闭和重复提交。
- 手机知识库阅读的导航规则以 [知识库功能说明](LIBRARY.md) 为准；主菜单隐藏规则必须随主壳样式加载，不能依赖尚未加载的文章组件。懒加载/失败占位也必须有返回路径。

## Orbit 对话工作区

宽屏显示会话侧栏、对话和既有记事板；窄屏通过输入栏“＋ → 历史对话”管理会话，记事板沿用抽屉。窄屏不再为对话列表单独占一行。生成状态只影响对应请求，不能禁用整个页面；下一条输入加入队列，取消与失败重试有明确反馈。知识卡片显示约两行摘要，未引用候选折叠；日程结果卡片允许键盘打开并复用现有编辑器。

输入栏以两组紧凑分段控件表达“指令 / 记事”和“Work Buddy / ChatGPT”；左侧加号、中央自增高输入、右侧发送/保存。具体模型、附件、历史与新对话集中在加号面板。两组控件支持点击、方向键以及明确的横向滑动释放；纵向手势继续交给页面滚动。切换方式不清空输入、附件或模型。记事隐藏 Provider/模型，独立上传或粘贴图片，与文字保存为同一卡片；聊天附件保留到切回指令后发送。成功消费来源草稿，较新的输入保留；具体图片/备份合同见 [架构](ARCHITECTURE.md#记事图片与草稿合同)。

模型选择是账号偏好，记住 Provider 与各 Provider 的具体模型 ID。首次没有偏好且 ChatGPT 已连接时从真实目录选择 Luna；以后目录排序或新版本不自动改选。未连接、读取失败、模型下线和偏好保存失败分别提示。不能用“最新”别名、空目录或不可用模型静默替换用户选择；设置中的 Work Buddy 默认解析模型与聊天选择独立。

### 对话与设置基础系统

普通回复使用安全 Markdown 子集（标题、列表、加粗、代码、链接），不执行 HTML、图片或任意协议链接。正文桌面 14px、手机 15px，行高 1.65；确认草稿与执行成功分别表达，终态只由服务器结果决定。已处理提醒移除动作按钮，历史动作未知时显示“已处理”。读取旧内容时不抢滚动，提供“有新回复”。

请求状态由认证事件流提供实际步骤，断线沿用轮询；不显示推理过程、虚构百分比或重复 Thinking。长任务显示耗时和取消，工具来源与步骤可展开。设置搜索只索引已挂载、当前角色可见的名称/描述/别名，绝不索引输入值。搜索结果滚动定位、聚焦可用控件并短暂高亮；稳定公开入口应给 SettingRow 显式 id。

Motion 沿用 CSS 与 TDesign 生命周期：按压/悬停 80ms（反馈）、消息和状态 120ms（新增/变化）、浮层 160ms（层级）、侧栏 220ms（空间）。使用统一 easing 和 opacity/小幅 transform；不做整页飞入、布局动画或弹跳。连续操作可直接反转，最长 240ms。reduced-motion 禁止位移、循环与平滑滚动，保留静态状态。实现位于 src/styles/orbit-foundation.css。

输入栏分段指示器使用 120ms transform，更多功能面板使用 160ms 小幅位移/透明度入场和退出；关闭意图立即处理，退出期间保留模态约束，结束后返回入口焦点。复用现有 token，规则位于 src/styles/composer.css；业务写入不等待动画结束。分段手势达到 8px 才判方向，水平距离超过竖直距离 1.4 倍才捕获，释放位移达到 24px 才选目标；取消、丢失捕获不提交。分段控件不随手跟随，不做速度投掷或 spring。

全局搜索、加号面板、日程表单和事项详情使用原生模态 dialog，背景不可交互，Tab 留在模态内；Escape、完成点击遮罩和关闭按钮走同一关闭逻辑，并返回入口焦点。表单未保存关闭需确认；保存/事项操作进行中阻止重复提交和关闭。失败保留表单或事项，只有服务端成功才关闭/移除。长详情与表单内容内部滚动，标题、错误和主要操作保持可达。已有其他领域浮层仍需逐项检查，不能据此声称全站模态已统一。

聊天状态刷新故障使用独立重连提示，成功刷新后自动恢复；不能覆盖发送、记事保存等用户操作错误。发送超时保留输入并说明结果尚未确认，相同内容重试沿用请求 ID。日程写入超时也不假装失败已回滚，要求先重新加载核对，避免重复创建。

模型能力/Provider 选择沿用语义输入颜色、边框和紧凑尺寸，未知模型显示读取提示，不能只留下空下拉箭头。暗色日历标题使用主文字色，周期页面使用实色背景；聊天和设置原生链接使用主题色，暗色提高亮度，避免浏览器默认深蓝。宽屏导航显示短名称，窄屏保留可访问标签。窗口变化的过渡帧和最终稳定布局分开验证。

## 8. 体验升级的实施方式

前端基础系统已有实现，主要入口是 `AiSchedulePanel.tsx`、`ChatMarkdown.tsx`、`useOrbitChat.ts`、`settings/SettingsSearch.tsx` 和 `styles/orbit-foundation.css`。这不代表全站组件和所有状态已经统一。实施状态、优先级与完成条件统一维护在 [体验升级执行清单](TASKS.md#uiuxmotion-体验升级执行清单)，具体版本成果见 [更新日志](../CHANGELOG.md)。

后续沿以下顺序逐块交付，每块形成可以操作的成果，不整体替换前端：

1. **聊天正确性与连续状态。** 先检查会话切换、输入归属、排队、取消、重试和草稿生命周期；创建/切换尚未结束时不能把新输入提交给旧会话。正在运行的模型请求不锁住后续输入。正文、待确认动作、工具过程和服务端执行结果分别渲染，完成状态不能从模型文字推断。
2. **聊天信息与附件。** 统一时间、警告、来源、附件、待确认与终态卡的字号、间距和语义色。工具步骤默认收起，保留查询、来源、耗时和失败恢复入口；阅读旧消息时保持位置。用真实聊天验收过程连续性，用合成数据覆盖错误和空态。
3. **设置与共享控件。** 在现有 SettingRow/SettingSection/TDesign 上统一尺寸、标签、说明、focus 和 disabled。稳定搜索项给明确 ID/aliases，搜索不重挂载分区、不索引输入值。先整理现有共享样式；同一种差异反复出现在多个调用方时才提取小组件。
4. **全站布局与浮层。** 按今日、日历/日程编辑、周期提醒、日报、知识库顺序审查 Header/Sidebar、Panel、Dialog、Dropdown、Tooltip、Toast、空态/读取失败。先修遮挡、焦点与信息密度，再统一边框/圆角/间距。成熟弹窗不为视觉统一重写业务；手写浮层补齐 Escape、返回焦点和窄屏内部滚动。
5. **Motion 与响应式验收。** 使用既有 CSS token 和 TDesign 生命周期。为动画注明层级、状态、来源去向或操作反馈目的；缺少这些目的时不添加。检查连续开关/取消、列表服务端成功后变化、长任务静态提示及 reduced-motion。低性能结论需真实设备/受控测量，不能只凭 transition 数量。

每块至少留出桌面和手机的明暗截图，以及键盘、长文本、空/加载/错误/禁用状态证据。390×844、430×932、768×1024、1440×900 为共同矩阵；笔记本和宽屏按布局变化补充。桌面保留紧凑多栏，先收起辅助 Panel，再使用抽屉；不统一套用手机信息密度。

## 9. 共享视觉与 Motion System

权威实现为 `styles/orbit-foundation.css`、`styles/composer.css`、`usePanelPresence` 与现有 TDesign 生命周期。主体用语义主题变量；品牌色表达选中和主要操作，语义色表达结果。字号以 12px 辅助、13–14px 控件、15px 手机聊天、16px 长文、24/28px 页面标题为基础；字重以 400/500/600 为主。间距使用 4/8/12/16/24/32px，圆角为控件 6、卡片 8、浮层 12px；普通卡片依靠一层边框，阴影仅表示浮层高度。窄屏主壳两行，移除品牌副标题和重复说明。

### 时间与运动原则

- `--orbit-motion-press:80ms`：即时控件反馈；`--orbit-motion-feedback:120ms`：状态/指示器；`--orbit-motion-overlay:160ms`：浮层；`--orbit-motion-panel:220ms`：面板空间。新过渡不得超过 240ms。
- 入场/反转用 `cubic-bezier(.2,0,0,1)`；退出用 `cubic-bezier(.4,0,1,1)`。不引入 spring，不允许 bounce/overshoot。
- 小组件只移动 4px，普通侧栏 12px；手机记事板从右边界进出。opacity 入场 0→1、退出 1→0，不降低可操作内容的稳定透明度。
- 优先 transform/opacity；颜色/边框只做短控件反馈。不动画化 width、height、top、left、大面积滤镜、图表计数或正文排版，不永久设置 will-change。
- 按实际服务端结果改变状态；退出只管理呈现生命周期。重复关闭去重，面板反转取消待关闭，不累积动画队列。
- 系统 reduced-motion 下取消位移、循环与平滑滚动，关闭直接完成，保留文本、图标、选中态和错误。手势仍有显式关闭按钮替代，纵向滚动不被截获。

### 交互规格

| 交互 / 触发条件 | 起始 → 结束状态 | 时间 / 曲线 | 目的与实现 |
| --- | --- | --- | --- |
| Hover / Pressed / Focus | 常态 → 语义底色/边框；焦点直接显示轮廓 | 80ms / 入场 easing；焦点 0ms | 及时确认可操作对象；CSS，不缩放正文或整张卡片 |
| 发送方式、Provider 分段选择 | 当前选中位置 → 相邻位置 | 120ms / 入场 easing | 表达同一控件的选中位置；CSS transform，共享布局仅限指示器 |
| 新消息 / 实际状态变化 | opacity 0、Y 4px → opacity 1、Y 0 | 120ms / 入场 easing | 识别新增信息；CSS；历史加载不逐条重放，不抢阅读位置 |
| 加号面板、周期/完成/改期 Dialog | opacity 0、Y 4px → 1、0；退出反向 | 160ms / 入场与退出 easing | 表达浮层层级，原生 dialog 约束焦点；CSS 与 React 呈现生命周期 |
| 手机记事板展开/关闭 | 右边界 → 靠右固定面板；退出反向 | transform 220ms，opacity 160ms / easing | 保持空间关系；CSS 与 `usePanelPresence`，反转取消待退出 |
| Thinking / AI 工具 / 排队 | 静态标签 → 实际步骤 → 确认草稿或终态 | 状态 120ms；工作圆点 1.8s opacity 循环 | 表达正在处理及具体步骤，显示耗时/取消；CSS；减动下圆点静止。不显示伪造百分比或推理内容 |
| 提醒 / 通知 / Success | 原状态 → 新消息或成功文字/图标 | 新消息 120ms；TDesign Toast 160ms | 指明结果与所属对象；复用既有消息/Toast。Badge 直接更新，不跳动、发光或跨屏飞入 |
| Error / Disabled | 当前表单 → 就地错误、焦点与禁用控件 | 颜色 80ms；错误定位 0ms | 让失败可修正，保持输入；不摇晃、不自动消失、不用动画掩盖部分成功 |
| 阅读返回 / Page transition | 原路由 → 目标路由或恢复的阅读位置 | 0ms；手动目录定位沿既有滚动 | 优先内容和阅读连续性；会话内按账号保存位置/筛选/卡片焦点，不做整页过渡。减动下目录定位直接完成 |

所有规格均可由现有 CSS、Pointer Events、React 和 TDesign 完成，本阶段不需要 Motion for React、其他动画库或 Rive。共享布局不扩展到日历格子、列表重排或卡片高度；慢设备的流畅性必须实测，不能从技术选型推断。

### 表单与阅读恢复

`OrbitDialog` 统一周期表单、完成证明、今日发送确认及周期改期：保存中阻止重复/关闭，失败聚焦弹窗内错误并保留草稿，未保存关闭确认。写入超时说明结果未确认；附件上传允许更长等待。登记完成成功、附件失败时保留完成 ID，只重试附件；网络结果未知时先从今日完成记录核对，不能承诺附件恰好一次。

周期提醒新建/编辑的紧凑 Demo 只作用于 `reminder-setup-dialog`：类型为单行三项切换，名称与提醒时间并排，数值及相关周期字段成组。提前提醒天数、优先级、地区、建议操作及生活事务模板在默认折叠的“更多设置”内，折叠入口显示配置摘要，原值和提交语义保持。默认折叠状态在四个目标视口内无需正文滚动；展开更多设置、错误和低高度时只滚动正文，标题、关闭及提交保持可达。沿用原生时间输入，公共时间迁移和其他页面改造须在用户确认实际 Demo 截图后实施。

知识库、日报列表与阅读器用会话内、有上限、账号隔离的位置缓存；返回保留筛选、已加载页数、阅读位置与卡片焦点。退出账号或浏览器刷新不承诺恢复位置，也不缓存正文/凭据。加载过渡帧与稳定截图分别记录。手机记事板不保留滑动关闭手柄，通过关闭按钮、遮罩或 Escape 关闭，编辑草稿在面板关闭/重开时保留；桌面缩窄时收起辅助面板，避免自动遮挡导航。

验收分别记录“源码实现”“合成浏览器”“真实账号”“用户体验评价”。截图工具失败时保留 DOM/布局核对和具体限制，不据此宣布视觉验收通过。没有用户实际评价时，不将整体体验写为已满意。


### 个人活动报告与连接入口

报告沿用 Orbit 主题，参考 Codot 的概览、宽幅趋势、局部双栏与分隔线阅读顺序。桌面节律/完成度并排；窄屏同序单栏。图表使用现有样式/SVG，无额外图表依赖；数据表、原对象明细、采集范围与未知值必须可见。零、未采集、部分采集分别表达，不渲染健康、推算专注时长或综合评分。

节律热图为只读概览，整体提供标题与说明，168 个小时格子使用非交互元素并保留 tooltip，不加入 Tab 顺序。“查看详细数据”展开带 caption 和行/列标题的 7×24 表格；键盘可进入表格滚动区域后直接离开，窄屏只在表格内部横向滚动，不提供逐小时钻取。

搜索留在右上角，其余个人入口收进可键盘操作的头像菜单。头像默认首字母，上传/移除有加载/失败状态。常驻两个 checkbox 移除；知识检索在 + 菜单与可取消标签表达，通知设置打开已有窗口。设置入口高亮对应控件，未知/无权限提示；不在 AI 对话内复制设置表单。

系统卡片标明 Orbit 通知、来源、时间和原对象。已投递、已读、已完成不混用；变更后的操作失效，继续聊只填草稿，不自动发送。记事链接不冒泡触发编辑，普通正文保留编辑入口。报告预览与明确发送操作分开，模型失败仍显示事实和重试。


### 第二阶段共享呈现

`layouts/PageFrame` 为普通内容页面提供有界滚动；聊天、日历和 Settings 保留各自工作区。`ui/ActionRow` 用于整行单一操作的标题、摘要与辅助信息，不嵌套其他操作；存在独立操作的业务行采用自己的语义布局。`Textarea compact autoGrow` 使短列表条目从单行高度自然增长，仍可编辑换行；默认多行控件保持原样。

`Menu navigation` 仅用于个人导航：桌面按实际可用高度显示，手机使用 Sheet。普通菜单、Select 和 Popover 不随之改变。Dialog 的 `canClose` 可接入领域未保存保护，`size="wide"` 只扩展空间，不接管业务草稿。

显著重组的页面保留同一合成数据、视口与主题下的改造前后浏览器截图，主动比较层级、密度、间距、操作主次和整体协调。测试成功但布局仍粗糙时继续调整；候选截图不表示用户已批准，也不覆盖既有黄金图。


知识库/日报筛选复用 `CompactFilterSheet` 对 ui Sheet 的薄组合；草稿、应用与服务器排序失败仍由页面持有。路由主操作用 ButtonLink 保持链接语义。成长页用单条等距里程碑数轴联动架构与故事，日期、版本、提交及证据仍可查，手机纵向阅读；不重复放分类快捷条、精选停靠条和成长列表。个人报告将周期导航与附加筛选分开，精确半开范围可展开，统计事实与预览/发送仍分层。


任务列表的完成、内容和更多是独立目标；article不再扮演包含其他button的button。可编辑日程/待办的内容行复用紧凑ActionRow，周期标题保持只读，不让点击标题直接登记完成。完整待办复用ui Dialog/Menu，Menu支持受控open供页面协调；异步请求、脏编辑和删除确认仍归feature。记事板、图片和复制预览在已有原生顶层弹窗中维持其生命周期，复制预览单独约束头部/滚动区，避免基础样式退场时失去容器。手机复制操作均衡成两列。


后台用户列表优先展示身份、角色、状态与共享权限，常用账户设置在受控详情中处理，危险操作折叠并保留当前账户/管理员保护和原确认请求。邀请码与调试日志独立分区，失败保留已读取内容，操作中禁止重复提交或关闭。登录注册复用公共控件和就地反馈。日历保留四种业务视图，窄屏周/月明确提示局部横滚，菜单支持键盘与返回焦点；布局滚动时跟随锚点，用户滚动时关闭。

Tools 中心每个应用仅有一个链接入口；独立应用保持原有视觉与数据合同，定向修复可读性、触控和键盘。扑克批量识别使用原生 dialog 保护焦点与 Escape，牌面按真实按钮表达收集状态；不改变计算、导入导出结构、存储键、slug 或 CSP。


日程时间选择器仍由原生业务弹窗持有，浮层按触发位置与视口高度选择上下方，避免被表单滚动区裁切；不将浮层移到原生顶层外。低高度与200%缩放需确认小时/分钟、取消/确定完整可见及Escape返回焦点。

### 第三轮用户反馈修订

通知的邮件、站内、浏览器和免打扰合并在同一设置组，免打扰开启后就近展开时间，保存/取消位于组末；保存字段和跨页草稿所有权不变。日报与知识库列表不重复放置设置按钮，记录经历统一进入头像菜单。知识库四项筛选使用统一受控 Popover，选择即生效、默认向下定位、低高度内部滚动，排序失败保留原排序；阅读返回仍恢复筛选。

聊天计划编辑/删除沿用语义按钮和主题状态；结果按创建、更新、删除或混合操作分别显示“已创建 / 已更新 / 已删除 / 已执行”，部分执行显示“部分操作已执行”。这里的计划状态不能暗示事项实际完成。通知和主动提醒共用 Lucide 线性图标按钮，完整操作名通过 hover/focus Tooltip 与可访问名称提供，相邻图标共用 TooltipProvider；开启时关联 aria-describedby，关闭时从可访问树排除，避免快速键盘切换留下多个提示。业务动作及失败反馈不变。

今日行动中心保留既有布局，优先级显示圆点和高/中/低；无发送、刷新页头按钮，进入、事项修改和数据变更事件继续重读，错误重试保留。周期提醒取消顶部统计卡片，创建/编辑的既有必填字段显示红色星号；必填语义仍由输入 required 表达，不改变默认值、业务规则和存储格式。

## 设置层级、成长播放与统计呈现

设置分类注册表维护父子关系。账户、日报、使用统计的侧栏子项与正文 tab 同步至路由；展开按钮单独表达 aria-expanded/aria-controls，当前子项使用 aria-current。敏感表单离开页签卸载，普通草稿继续归 SettingsState 管理。

项目成长采用数轴、架构与故事联动的全宽舞台，详细统计与证据默认收起；桌面首屏适配、手机自然纵向滚动，长内容或完整图允许整页增长，不设嵌套竖滚。数轴全部里程碑等距可达，重要节点区分形状/颜色，支持悬停/焦点提示与方向键、Home/End、Enter/Space。五站精选及全部里程碑各播放一次，沿用快照明确标注且不重复新增动画；简明/完整为明确分段切换，清除仅作用于模块聚焦。真实关系及混合变化数量完整保留，变更颜色与聚焦共存。自动推进不更新URL、不抢焦点、不滚动正文；视口外/后台暂停并保留剩余时间，减动默认最新静态记录。曲线入屏绘制，真实值、统计口径及缺失规则不变。

个人活动报告使用执行蓝、完成绿、风险橙、知识青、AI 紫的语义配色，结合图标、标题、分隔线及浅底区分模块。默认筛选/历史管理进入设置；周期为图标导航，自定义范围通过共享 Popover 和分钟级 DateTimePicker 编辑，应用前不改变查询。

AI对话的俏皮话独立于真实步骤显示，使用单个小型轻旋转图标与中文引号，每条独立随机停留2–5秒再换句，允许个别文案自然使用波浪号。现有随机袋避免连续重复；切换淡出/淡入，使用本地文案池的隐藏尺寸占位稳定换行高度，不增设聊天消息或写入历史。文字层级弱于正式回复，aria-live=off；后台暂停计时和旋转，队列终态/组件卸载清理计时器。prefers-reduced-motion关闭旋转与渐变，不制造进度、自动滚动或高频读屏提示。真实状态和操作始终可用。

嵌套浮层中的分钟选择面板使用其实际fixed包含块换算视口坐标，避免受Popover定位变换影响而重复偏移；常规弹窗与低高度仍使用同一视口边界。统计周期前后及重置图标采用共享Tooltip，提示随周/月/年变化，浏览器返回同步默认周期。

周期提醒消费 `?edit=` 深链接时通过 React Router 替换当前路由，保持地址与路由状态同步；不能只调用原生 history 清空地址，否则保存后刷新列表可能再次打开编辑器。回归必须观察列表刷新后的关闭状态。


记事 composer 使用局部 note 语义色控制边框、按钮、caret及键盘焦点，明暗主题分别取 token；指令恢复品牌色。成长规模曲线保留独立尺度及日期范围，稀疏测试数量使用独立证据列表，缺失明确为“未记录”，不能补零、求和或推断历史质量。


## 提示与分层确认

普通结果使用Toast/就近反馈，表单校验贴近字段并聚焦错误输入。普通单条删除、归档和日期转换可使用ConfirmPopover；周期及历史删除、账号危险操作、经历永久删除、对话历史清理、观点正式决定、邮件重发和未保存放弃使用ConfirmDialog。

useActionConfirmation固定打开时的目标和回调，同一时刻只持有一项请求。确认后执行一次，busy期间禁用关闭/重复确认，失败保留内容和重试；false结果视为未完成。Dialog/Popover的portalContainer可指向所属原生HTML dialog，缺省使用body，不传null阻止挂载。Escape只处理当前层，取消返回原控件。失去锚点时采用Dialog，菜单项不能作为关闭后即消失的确认锚点。

OrbitDialog的canClose继续同步判断，dirty时返回false并由discardMessage启动应用内确认，确认才调用原关闭回调。Settings站内导航的同步confirm及dirty-only beforeunload为具名保留边界；系统通知及权限不能改为页面Toast。Tools保持独立页面风格和本地格式，通过工具内HTML dialog处理输入和危险确认，不引入主站框架。
