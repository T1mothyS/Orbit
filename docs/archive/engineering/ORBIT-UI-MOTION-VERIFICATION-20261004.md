## 实现

保留聊天、TDesign、路由/队列/确认边界。线性导航减少品牌副标题/重复标题和空态占位；页面/正文/辅助信息使用共享字号、间距、圆角/边框。颜色表示选择和状态，浮层一层阴影。日报沿既有文档阅读，知识库技术信息/版本/关联标识折叠；导出为次要动作。

周期、今日完成记录/发送确认、本期改期统一模态、忙/未保存保护、失败聚焦与输入保留。完成成功后附件失败，保留完成 ID、仅重试附件；超时结果未知。完成空账单日期/备注 API 转换修正，空值可清空、省略保留、非法日期不落库。

手机记事板背景隔离、焦点返回、专用手柄拖动与显式关闭；短拖/纵向/取消不关闭，重开保持草稿，桌面缩窄收起。Motion 为 80/120/160/220ms，无 spring、bounce、全页飞入、计数滚动、发光或新依赖。减动保留静态状态。

阅读恢复按账号、有上限、会话内，仅保存位置/筛选/焦点；拒绝过期异步结果。登录可访问名称/自动填充；管理浮层兼容 TDesign 弹出层并约束 Tab/返回焦点。

- 周期 503：保存中字段/关闭/提交禁用，失败名称保留，未保存关闭可取消，恢复保存并返回焦点。
- 完成证明：登记 POST 一次、附件 POST 两次；首次上传 503 保留文件/完成 ID、锁住已登记元数据；重试只上传附件并进入下一周期。
- 今日刷新 503：错误可重读、事项保留。完成金额三位小数被拒绝并聚焦；改为有效金额、账单留空保存后重新打开，值一致。
- 知识库教程筛选、列表约 1605px 与卡片焦点保留；长文约 2815px，浏览器返回/实际点击返回后重开保持。目录加载/恢复顺序独立处理。
- 手机记事短拖/纵向不关闭、长拖关闭、未保存文字重开保留；缩窄不自动遮挡导航。
- 设置手机搜索邮箱并定位分区，未写配置；管理 Tab 连续遍历留在模态、关闭回入口。没有轮换凭据/修改角色/删除账号。
- 日报正文刷新 503 保留已加载正文，显示就地错误；恢复后重试提示消失、正文仍可见。刷新入口放在“更多”菜单。合成 WorkBuddy 队列提交/回复完成，输入框在提交后可继续使用；合成目录不是实际 OAuth 授权。

新增自动回归覆盖完成可选空值/省略/非法日期/账号隔离，以及读超时与写结果未知。418/418 自动测试、最终 typecheck、Web/Electron staging 构建、Tools 与成长页检查、diff 检查通过。末次仅调整日报刷新呈现后重跑类型检查/构建，服务端与测试输入未改变。合成 worker 回复不代表真实模型。官方 registry 完整依赖 audit 当前 21 项（19 high/1 moderate/1 low）；依赖未修改，历史 23 项是原日期结果。Mermaid/布局器既有大 chunk 提示仍存在，不据此假定低性能体验通过。

## 设备与长期边界

viewport 不是物理手机：软键盘、安全区、触摸拖动、系统返回、OS reduced-motion、低性能流畅性及实际跨设备模型恢复不能据此宣告通过。设备清单：输入时底栏可见/可发送，横拖关闭而短拖/纵拖取消，返回恢复文章位置，减动状态仍可理解，另一设备登录恢复精确模型。长期 OAuth/额度/网络与自然提醒另观察。

现实风险：附件网络响应丢失时须先核对，避免重复附件；阅读只在当前会话恢复，不承诺刷新/登出同步；物理设备的键盘/手势可能与桌面模拟不同。
