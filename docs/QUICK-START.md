# Orbit 快速上手
<!-- product-help: user -->

- Status: FEATURE；对应 Web、Electron 与 Android 在线页面。
- Authority: 当前功能源码；完整行为和配置边界见 [使用指南](USER-GUIDE.md)。
- Update trigger: 入口、确认流程、设置归属或帮助行为变化。

先从下面一项任务开始。头像菜单的“使用指南”打开 `/help`，设置进入 `/settings`。

| 要做什么 | 从哪里开始 | 操作要点 |
| --- | --- | --- |
| 创建日程或待办 | 日程，或 AI 对话 | 描述事项，核对时间与类型；AI 草稿确认后才写入。无固定日期的待办可放入挂起区。 |
| 管理重复事务 | 周期提醒 | 设置周期，逐次登记完成；在历史中核对已完成实例。 |
| 保存记事与继续聊 | AI 对话中的记事入口 | 记事可以直接保存；发送到对话不会自动完成来源记事。 |
| 阅读知识与记录经历 | 知识库 | 明确提及知识库才检索；经历整理后预览确认再保存。 |
| 设置提醒 | 设置 → 通知与提醒 | 核对共享邮箱、时间、渠道和免打扰；Android 还需客户端权限与设备绑定。 |
| 调整日报与周报 | 设置 → 日报；设置 → 通知与提醒中的 Orbit Weekly | 分别配置个性化、来源与邮件。保存偏好不立即生成或补发；自动周报默认关闭。 |
| 修改密码 | 设置 → 账户与安全 | 验证当前密码后更新；成功后使用新密码重新登录。独立授权边界见 [账户与安全](USER-GUIDE.md#账户与安全)。 |

`/help` 的“询问 AI”只选择固定产品问题，追加到原对话草稿末尾，并保留已有文字和图片。它不会自动发送；请检查后自行发送。

个人资料在账户分类中编辑，日报偏好在日报分类中编辑，两者共用 Cloud Context 的版本与数据。分类间切换保留普通草稿；离开设置会保护未保存修改。密码、API Key、邮箱授权码和一次性令牌离开相应页面后清空，不写浏览器草稿存储。具体保存、冲突和恢复边界见 [架构](ARCHITECTURE.md#settings-v3-路由与状态)。

页面显示“已保存”、服务端接受、真实外部服务执行和手机/邮箱到达是不同结果；分别到对应功能状态与运行记录核对。
